# v0.1.17 - AIDP-first agent development

Adds `aidp-agent-development` for agent code, prompts, MCP tools and iterative
conversation tests. The preferred development loop uses existing AIDP compute,
the smallest editor/tool test and Playground traces. Endpoint publication is a
separate explicitly requested phase followed by actual endpoint tests.

The skill routes to installed official Oracle agent tooling after compatibility
checks; it does not redistribute Oracle code, invent wrapper commands or
provision anything on installation. References document current Oracle editor
and packaging differences, pinned GitHub samples (UPL-1.0), OpenAI skill
boundaries and progressive disclosure. Existing migration skills remain intact.

Preflight now checks the existing Sentrux baseline and creates one only when
absent. This preserves the prior release's documented degradation.

## Validation and limits

- Official skill validator: all 12 skills passed, using an existing Python
  environment with PyYAML; no validation dependency was installed.
- Manifest identity/version, skills directory, routing prompt and new local
  reference links passed focused packaging checks.
- Existing run-summary and diagnostic-evidence regression suites passed.
- Independent read-only review found no blocking workflow, authorization or
  compatibility issue. Only the six intended files were applied; bytecode
  and staging artifacts are excluded from the update.
- Sentrux before/after: unchanged quality 7297 against the original 8695
  baseline; gate FAIL remains pre-existing. No cycles or god files, coupling
  unchanged at zero. The original baseline SHA-256 was preserved. No custom
  rules or Graphify graph are configured; no graph was initialized.
- Preflight/postflight retain and report that structural failure; this is not
  an all-green validation or a claim that the prior architecture debt is fixed.

No live AIDP, model, compute, MCP or paid API tests are part of this plugin change.
Documentation establishes supported workflows, not availability or latency in
every tenancy. Production deployment, GitHub publication and a live development
pilot remain separate operations.
