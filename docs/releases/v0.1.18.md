# v0.1.18 - Oracle memory and external framework guidance

The agent development skill remains a workflow standard. It routes live agent
operations to the separately installed official Oracle plugin and recommends
relevant upstream LangChain/LangGraph skills as external dependencies. No
LangChain skill content is copied into this migration plugin.

The new reference explains managed context versus extracted memory, sharing,
retention, authenticated isolation and bounded acceptance tests. Compatibility
rules preserve AIDP package versions/lifecycle, models, guardrails, persistence,
secrets and telemetry destinations; generic framework examples do not authorize
migrations or repeated paid calls.

Installing this version performs no compute, memory, library, scheduling or
agent deployment changes. The local Codex adapter `langchain-skills-codex` is
an independent adaptation, not an official LangChain plugin for Codex.
