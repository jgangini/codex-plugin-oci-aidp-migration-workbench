# v0.1.19 - Verified CLI operations and Browser acceptance

CLI is the primary execution path for repeatable AIDP operations with verified
contracts. The development skill distinguishes supported wrapper commands,
signed REST/project helpers, operations whose contracts still need the native
UI, and visual acceptance that remains in Browser.

File upload, compute association, TEST package refresh, invocation and published
deployment are separate operations. Successful metadata writes or ACTIVE state
do not establish the code revision actually served. Existing PROD state,
authenticated identity, conditional writes and uncertain paid-run reconciliation
remain protected across both execution paths.

This update preserves the two existing uncommitted CLI/Playground guidance
changes and extends them; it adds no executable cloud command, dependencies,
permissions, MCP server or deployment. Installation does not run an agent.

## Validation

All twelve package skills pass the official skill validator. Both existing offline
regression suites pass, including attempt classification, redaction, output
parsing and overwrite protection. Their first sandboxed attempt could not write
Temp fixtures; the same suites passed with the required filesystem access.
A read-only independent review checked verified CLI sync, unsupported TEST
refresh, visual streaming acceptance, stale code behind ACTIVE, and uncertain
paid starts; no concrete contradiction was found.

The Codex CLI installed version 0.1.19 from the existing local marketplace.
The manifest and two changed guidance files match source bytes exactly;
the local plugin remains enabled and both disabled duplicates remain disabled.
No AIDP agent, credential, deployment or paid call was changed by this update.

Preflight and postflight both report the unchanged historical Sentrux failure
(quality 8695 versus 7297, zero coupling/cycles/god files); the original baseline
is preserved. Custom rules and Graphify are not configured in this plugin repo.
This is not an all-green architecture validation or native AIDP acceptance.
